# Игры TOKITO

Квиз «Ваша комната по-японски» и 8 коротких игр для покупателей TOKITO: «Гибкий шланг», «Путь Кэндзи», «Дом Кэндзи», «Протечка», «Плиточный пасьянс», «Колода Tokito», «Собери смеситель», «Найди пару».

Один файл `index.html` и картинки в `img/`. Ссылки на чат-бота, Telegram-канал и текст бонуса задаются в `CONFIG` в начале скрипта.

Онлайн-стол в «Колоде Tokito» работает только внутри Claude. На GitHub Pages доступна игра с ботами.

Что есть в версии 2: реплики и кадры Кэндзи, альбом «Дни Кэндзи» на 12 кадров, задание дня со счётчиком дней подряд, карточка для сторис с QR, ссылка-вызов другу, сезонные события (Новый год 15.12–15.01, сакура 1–10 марта; предпросмотр через `?season=ny` или `?season=sakura`), звук и вибрация, керамические плитки, новая колода, промокод в бонусе (`CONFIG.PROMO`), отправка подборки из квиза в чат-бот (`CONFIG.BOT_USERNAME`).
