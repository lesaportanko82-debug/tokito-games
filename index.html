TOKITO · игры для клиентов

Одно приложение, девять игр

По документу Елены Пахмутовой «Tokito · Игры для клиентов». На главном экране человек сам выбирает, во что сыграть.

  1. Квиз «Ваша комната по-японски» для новых гостей
  2. «Гибкий шланг», змейка
  3. «Протечка», сапёр
  4. «Собери смеситель», пазл
  5. «Найди пару», мемори
  6. «Путь Кэндзи», платформер
  7. «Дом Кэндзи», три в ряд
  8. «Плиточный пасьянс», косынка
  9. «Колода Tokito» по мотивам уно

По QR-коду из коробки (ссылка с ?from=qr) первыми показываются игры для покупателей.
